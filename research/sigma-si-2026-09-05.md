### 1.4 Why: the spike must dominate the noise (HEURISTIC model, PROVED exact instances)

For `t ≠ 1`, `g(t)` is a signed sum over the `mn` pairs; its exact mean square over `t ∈ F_p` is `R_χ − n²s_A²/p ≤ R` (Theorem 2.1 of the crux note, re-proved in §3.2 below). If the dilates behaved like Gaussians of variance `≈ R`, the expected number of `t ≠ 1` with `|g(t)| ≥ ½|S|` would be `(p−2)·2Φ̄(z/2)`, `z² = S²/R`. On the 1243 stored crux rectangles (§4) the actual mean square `V'` of `g` over `t ∉ {0,1}` satisfies `0.17 ≤ V'/R ≤ 0.96` (median `0.72`), and in the 1235 cases where the model predicts `|D| < 2` the median of `|D|/prediction` is `1.00`. The point is that `z² = S²/R ≤ β²·mn` (bias `β`), so at `mn = 64`, `β = ½` one has `z = 4`, `2Φ̄(2) = 4.6 %`, and `|D| ≈ 0.046p` — linear in `p`; even at `β = 1`, `z = 8` gives `2Φ̄(4) = 6.3·10^{−5}`, exceeding `8 log₂ p/p` for `p ≳ 3·10^6`. The size hypothesis `|A||B| ≥ 64` is therefore of the wrong shape: any log-type bound needs `z² ≳ 8 ln p`, and the subgroup witnesses of §1.1 (`z² = M_H²/|H| ≤ 2 ln p`) and the random-like ones (`z² = 16`) are exactly the low-SNR corner.

The linear growth is a theorem at the smallest sizes:

**Proposition 1.1 (PROVED).** Let `A = {a}` and `B = {b₁,b₂} ⊆ F_p^*` with `|T_B(a)| = 2` (bias `1`). Then `|D_{1/2}(A,B)| = (p+1)/2 − [χ(b₁) = χ(b₂)]`. Let `B = {b₁,b₂,b₃} ⊆ F_p^*` with `|T_B(a)| = 3`. Then, with `σ = Σ_{i} χ((b_j − b_i)(b_k − b_i))` (`{i,j,k} = {1,2,3}`), `p + σ ≡ 0 (mod 4)` and `|D_{1/2}(A,B)| = (p + σ)/4 − [|T_B(0)| = 3]`.

*Proof.* `g(t) = Σ_b χ(ta+b) = T_B(ta)`, so `D = {t ≠ 0 : 2|T_B(ta)| ≥ |T_B(a)|}` and `t ↦ ta` is a bijection of `F_p^*`; hence `|D| = #{x ≠ 0 : 2|T_B(x)| ≥ |T_B(a)|}`. For `n = 2`: `2|T_B(x)| ≥ 2` iff `T_B(x) ≠ 0`. For `x ∉ −B`, `T_B(x) = 0` iff `χ(x+b₁)χ(x+b₂) = −1`; since `Σ_{x} χ(x+b₁)χ(x+b₂) = −1` (`b₁ ≠ b₂`, background fact) over the `p−2` values `x ∉ −B`, the number with product `−1` is `(p−1)/2` and with product `+1` is `(p−3)/2`; at `x = −b_i`, `T_B = ±1 ≠ 0`. So `#{x ∈ F_p : T_B(x) ≠ 0} = (p−3)/2 + 2 = (p+1)/2`, and `x = 0` (where `T_B(0) = χ(b₁)+χ(b₂)`) is removed iff `χ(b₁) = χ(b₂)`. For `n = 3`: `2|T_B(x)| ≥ 3` iff `|T_B(x)| ≥ 2`; for `x ∉ −B`, `T_B(x) ∈ {±1, ±3}` and this means all three `χ(x+b_i)` are equal; for `x = −b_i`, `T_B(x) = χ(b_j−b_i)+χ(b_k−b_i) ∈ {0,±2}` and this means `χ((b_j−b_i)(b_k−b_i)) = 1`. Expanding `Π_i(1 ± χ(x+b_i))` and summing over `x ∈ F_p`: the constant term gives `p`, single factors give `0`, pairs give `−1` each (three pairs), and the triple `Σ_x χ((x+b₁)(x+b₂)(x+b₃)) =: −a_E` appears with opposite signs in the two products. Writing `N_±` for the number of `x ∉ −B` with all `χ(x+b_i) = ±1`, one gets `8N_+ = p − 3 − a_E − Σ_i Π_{j≠i}(1+χ(b_j−b_i))` and `8N_- = p − 3 + a_E − Σ_i Π_{j≠i}(1−χ(b_j−b_i))` (the corrections are the `x = −b_i` terms, where one factor equals `1`). Adding, `a_E` cancels and `Π(1+χ)+Π(1−χ) = 2(1 + χ(b_j−b_i)χ(b_k−b_i))`, so `N_+ + N_- = (p − 6 − σ)/4`. The boundary points contribute `#{i : χ((b_j−b_i)(b_k−b_i)) = 1} = (3+σ)/2`. Total over `x ∈ F_p`: `(p − 6 − σ)/4 + (3+σ)/2 = (p+σ)/4`; remove `x = 0` iff `|T_B(0)| = 3`. Integrality of `(p+σ)/4` follows. ∎

Checked for every `B` at all primes `7 ≤ p ≤ 1500` (`n = 2`) and `7 ≤ p ≤ 400` (`n = 3`), 1 919 941 cases in all, zero failures; the verifier repeats the check at `p ∈ {101, 211, 401}`. Note that the elliptic-curve trace `a_E` of `y² = (x+b₁)(x+b₂)(x+b₃)` drops out: `|D_{1/2}|` for complete `1×3` rectangles is `p/4 + O(1)` for *every* `B`.

The exhaustive maxima of `|D_{1/2}|` over all rectangles with bias `≥ ½` for `(m,n) = (1,2), (1,3)` at all `p ≤ 1500`, resp. `≤ 400`, for `(1,4), (1,5)` at `p ≤ 71` and for `(2,2), (2,3), (3,3)` at `p ≤ 31` (all `A, B` up to dilation) are recorded in the results file (`small_exact`); `max |D|/p` stays in a fixed window: `0.500`–`0.571` for `(1,2)` (`750/1499` at the top), `0.143`–`0.308` for `(1,3)` (`100/397`), `0.73`–`0.92` for `(1,4)`, `0.46`–`0.49` for `(1,5)`, `0.81`–`0.92` for `(2,2)`, `0.73`–`0.92` for `(2,3)`, `0.55`–`0.92` for `(3,3)` (`21/31`), i.e. `|D_{1/2}| = Θ(p)`. These sizes fall outside SI's hypothesis `|A||B| ≥ 64`, and they show that no hypothesis of the form `|A||B| ≥ c` can give a bound `o(p)`.

## 2. Logic (Task 1): exact implications (PROVED) and non-implications

**Definitions.** For `0 < ε < 1`, `δ > 0`:

* `C(ε,δ)`: for `p > p₀`, all `A,B ⊆ F_p` with `|A|,|B| > p^ε`: `|S(A,B)| ≤ p^{−δ}|A||B|`. `C` = "for every `ε` some `δ`".
* `USB(ε,δ)` (uniform shifted-subgroup bound): for `p > p₀`, all `H ≤ F_p^*` with `|H| > p^ε`: `M_H ≤ p^{−δ}|H|`. `USB` = "for every `ε` some `δ`". (Bourgain's Problem 5 in Chang's survey, per the structured note §1; OPEN.)
* `NB(ε)` (no biased rectangles): for `p > p₀`, all `A,B ⊆ F_p^*` with `|A|,|B| > p^ε`: `|S(A,B)| < ½|A||B|`. `NB` = "for every `ε`".
* `NB'(ε)` (product-only reading of (d)): the same with the hypothesis `|A||B| > p^{2ε}` only.
* `WSB(κ)` (weak subgroup bound at scale `κ log p`): for all `p` and all `H` with `|H| > κ ln p`: `M_H < |H|/2`.
* SI₁, SI₂ as above; SI\*(C, K): for all `p`, all `A,B ⊆ F_p^*` with `|S| ≥ ½mn` and `S² ≥ C·R·ln p`: `|D_{1/2}| ≤ K log₂ p`.

**Proposition 2.0 (NB' is false; PROVED).** `NB'(ε)` fails for every `ε < ½` at every prime: `A = {1}`, `B = {b ∈ F_p^* : χ(1+b) = 1}` has `|B| = (p−3)/2`, `|A||B| > p^{2ε}` for large `p`, and `S(A,B) = |B| = |A||B|`. So statement (d) of the task must be read with `|A|,|B| > p^ε`, which is `NB(ε)`.

**Theorem 2.1 (subgroups and cosets; PROVED).** Let `H ≤ F_p^*`, `N = |H|`, `A ⊆ F_p^*`.

1. `g_{A,H}(th) = χ(h) g_{A,H}(t)` for `h ∈ H`. Hence `|g_{A,H}|` is constant on cosets of `H`; if `|S(A,H)| ≥ ½|A|N` then `D_{1/2}(A,H)` is a union of cosets of `H` and contains `H`, so `|D_{1/2}(A,H)| ≥ N`.
2. There exists `A ⊆ F_p^*` with `|S(A,H)| ≥ ½|A|N` iff `M_H ≥ N/2`; `A = cH⁺` with `|T_H(c)| = M_H` realises `|S(A,H)| = M_H|A|`, and every `A` has `|S(A,H)| ≤ M_H|A|`.
3. For `c ∈ F_p^*`: `S(tA, cH) = χ(c) S(tA/c, H)` for all `t`, hence `D_{1/2}(A, cH) = D_{1/2}(A/c, H)` and the bias is unchanged. Cosets reduce to subgroups.
4. Consequently, for `N > 8 log₂ p`: [SI₁ holds for every pair `(A, H)`] ⟺ `M_H < N/2`. In particular `SI₁ ⇒ WSB(8/ln 2)`, i.e. `M_H < |H|/2` for all `|H| > 8 log₂ p = 11.54 ln p`.
5. For `N ≤ 8 log₂ p` clause SI₁ can fail for `B = H` (the witness of §1.1, `N = 8`; and `N = 1`, `B = {1}`, which is the `1×64` family of §1.2 after `A ↔ B`).

*Proof.* (1) `g(th) = Σ_{a}Σ_{h'} χ(tha + h') = Σ_aΣ_{h'} χ(h)χ(ta + h'/h) = χ(h) g(t)` since `h' ↦ h'/h` permutes `H`. If `1 ∈ D` (which is the biased case: `2|g(1)| ≥ |g(1)|`) then `|g(h)| = |g(1)|` gives `H ⊆ D`, and `t ∈ D ⇒ tH ⊆ D`. (2) `T_H(ch) = χ(h)T_H(c)` (same computation), so `S(cH⁺, H) = Σ_{h∈H⁺} T_H(ch) = |H⁺| T_H(c)`; conversely `|S(A,H)| = |Σ_{a∈A} T_H(a)| ≤ |A| M_H` as `0 ∉ A`. (3) `Σ_{a,h} χ(ta + ch) = χ(c) Σ_{a,h} χ(ta/c + h)`. (4) If `M_H ≥ N/2` take `A = cH⁺`: `|A| ≥ N/2`, `|A|N ≥ N²/2 ≥ 64` (as `N > 8 log₂ p ≥ 12`), bias `M_H/N ≥ ½`, and by (1) `|D| ≥ N > 8 log₂ p`. If `M_H < N/2` no pair `(A,H)` is biased and SI₁ is vacuous. (5) is §1.1–1.2. ∎

Numerically (verifier, from scratch): for all 546 primes `11 ≤ p ≤ 4000` and all 3890 subgroups with `2 ≤ |H| ≤ 2√(p+1)` (above this `M_H ≤ √(p−|H|) < |H|/2` automatically, see §3.2), `M_H < |H|/2` holds for every `|H| > 8 log₂ p`; the largest `|H|` with `M_H ≥ |H|/2` is `4.84 log₂ p` (`p = 2269`, `|H| = 54`, `M_H = 27`), and the largest `M_H/|H|` above `8 log₂ p` is `0.348` (`p = 2137`, `|H| = 89`, `M_H = 31`). So the subgroup consequence of SI₁ is true on this range while SI₁ itself is false: the clause fails only through *small* subgroups (`|H| ≤ 4.84 log₂ p` here), exactly the low-SNR regime.

**Theorem 2.2 (what SI\* says about subgroups; PROVED).** `SI*(C, K)` implies `M_H < |H|/2` for every subgroup with `|H| > max(4C ln p, K log₂ p)`. For `C = 8`, `K = 2`: `|H| > 32 ln p`.

*Proof.* If `M_H ≥ N/2` with `N = |H|`, the pair `(cH⁺, H)` has `S = M_H|H⁺|`, `R = N|H⁺|²` (every ratio `h/(ch') ∈ c^{−1}H` has multiplicity `|H⁺|`), so `z² = M_H²/N ≥ N/4 ≥ C ln p` when `N ≥ 4C ln p`, bias `≥ ½`, and `|D| ≥ N` by 2.1(1). SI\* forces `N ≤ K log₂ p`. ∎

**Proposition 2.3 (the remaining implications).**

1. `C ⇒ USB` (PROVED; structured note Theorem 2.2(b), re-proved: apply `C(ε',δ)` with `ε' < ε` to `(cH⁺, H)`, `|cH⁺| ≥ |H|/2 > p^{ε'}`; `M_H|cH⁺| = |S(cH⁺,H)| ≤ p^{−δ}|cH⁺||H|`).
2. `USB ⇒ C` restricted to pairs `(A, H)` and to unions of boundedly many cosets (PROVED; structured note Theorem 2.2(a): `|S(A,H)| ≤ |A|M_H`). `USB ⇒ C` in general: OPEN; the only reductions tried (containers, coset decomposition) fail with witnesses (structured note Prop. 4.5, Obstruction 5.2), so no implication is claimed.
3. `C ⇒ NB` (PROVED: `p^{−δ} < ½` for large `p`). `NB(ε)` for `ε > ½` is unconditional (PROVED, Prop. 3.1 below: bias `≥ ½` needs `mn ≤ 4(p − max(m,n))`, impossible for `m,n > p^ε`, `ε > ½`, `p` large). `NB ⇒ C`: OPEN; the precise gap is a level: `NB` says the level set `{A : |S(A,B)| ≥ ½|A||B|}` is empty above size `p^ε`, `C` asks the same at level `p^{−δ}`, and no amplification from a constant level to a power saving is known (Lemma 2.3 of the structured note shows bias `η` is the statement `τ_m(B) ≥ η|B|` about the mean of the `m` largest `|T_B|`; monotonicity in `η` goes the wrong way).
4. SI and `C`, `NB`: since SI₁ and SI₂ are false, `X ⇒ SI` is false for every true `X`, and `SI ⇒ X` is vacuous; the meaningful comparisons are with SI\*. `SI* ⇒ NB` and `SI* ⇒ C` are not to be expected for the reason of the crux note Prop. 4.5(4): the hypothesis and conclusion of SI\* are invariant under `(A,B) ↦ (uA,B)` (`R`, `|S|` and `|D|` are; `D ↦ u^{−1}D`), so SI\* is a statement about the dilation orbit and is satisfied by any profile consisting of a single spike, including `|S(A,B)| = |A||B|`; `NB` asserts the absence of the spike. Conversely `NB` and `C` say nothing at sizes `≤ p^ε` for any fixed `ε`, while SI\* is non-vacuous from `mn ≈ 8 ln p` on (`z² ≤ mn`), so `NB ⇏ SI*`, `C ⇏ SI*` in the sense that the ranges do not overlap: SI\* restricted to `|A|,|B| > p^ε` is implied by `NB(ε)` vacuously, and SI\* below that range is independent of `NB`.
5. `USB` versus SI\*: `USB` is about `|H| > p^ε` and gives `p^{−δ}`; SI\* yields only Theorem 2.2 (`M_H < |H|/2` at scale `32 ln p`). Neither implies the other: `USB` is silent at `|H| ≈ log p`, and `WSB` is a constant-level statement.

## 3. Restricted classes (Task 2)

### 3.1 Large rectangles (PROVED)

**Proposition 3.1 (Chung range).** If `|S(A,B)| ≥ ½mn` then `mn ≤ 4(p − n)` and `mn ≤ 4(p − m)`. Hence if `mn > 4(p − max(m,n))` no rectangle of sizes `(m,n)` is biased, the level set `{t : |g(t)| ≥ ½mn}` is empty for every `(A,B)` of these sizes, and SI (in any form) is vacuous there. In particular this holds for `mn > 4p`, and so for `|A||B| > p^{1+ε}` once `p > 4^{1/ε}`.

*Proof.* `Σ_{x∈F_p} T_B(x)² = n(p−n)` (expand; `Σ_x χ(x+b)χ(x+b') = p−1` or `−1`), so by Cauchy–Schwarz `S(A,B)² = (Σ_{a∈A} T_B(a))² ≤ m·n(p−n)`; with `S² ≥ m²n²/4` this gives `mn ≤ 4(p−n)`. Swap the roles of `A` and `B`. The bound depends only on `(m,n)`, hence applies to every dilate `(tA, B)`. ∎

**Proposition 3.2 (the provable range of SI₁).** For `A ⊆ F_p^*` (so `0 ∉ A`):

    Σ_{t∈F_p} g(t)² = p·R_χ(A,B) − n²·s_A²,   R_χ = Σ_r (Σ_{b/a = r} χ(a))²,   s_A = Σ_{a∈A} χ(a),

hence `|D_{1/2}| · S²/4 ≤ Σ_{t≠0} g(t)² ≤ p R_χ ≤ p R` and

    |D_{1/2}(A,B)| ≤ 4pR_χ/S² ≤ 4pR/S² ≤ 16pR/(mn)² ≤ 16p/max(m,n)   (the last two for bias ≥ ½).

Therefore SI₁ holds for every biased rectangle with `max(m,n) ≥ 2p/log₂ p`, and by Prop. 3.1 such a rectangle has `min(m,n) ≤ 4(p − max)/max < 2 log₂ p`. Under the SNR hypothesis `S² ≥ 8R ln p` the same inequality gives the unconditional bound `|D_{1/2}| ≤ p/(2 ln p)`.

*Proof.* For `a, a' ≠ 0`: `Σ_t χ(ta+b)χ(ta'+b') = χ(aa') Σ_t χ((t + b/a)(t + b'/a'))`, which is `χ(aa')(p−1)` if `b/a = b'/a'` and `−χ(aa')` otherwise. Summing over `(a,b),(a',b') ∈ (A×B)²`: `p Σ_r σ_r² − (Σ_{a}χ(a))² n²` with `σ_r = Σ_{b/a=r} χ(a)`; `|σ_r| ≤ μ_r` gives `R_χ ≤ R`, and `μ_r ≤ min(m,n)` gives `R ≤ mn·min(m,n)`. ∎ (Identity checked exactly on the 1243 stored rectangles and 90 random pairs; the bound `|D| ≤ 4pR/S²` on all of them.)

So SI₁ is PROVED exactly in the window `2p/log₂ p ≤ max(m,n)`, `min(m,n) < 2 log₂ p`, and vacuous above `mn > 4(p − max(m,n))`; §3.4 shows nothing else is reachable by moments.

### 3.2 Subgroups and cosets

Theorem 2.1 is the complete answer: `D_{1/2}(A,H)` is a union of `H`-cosets, `D_{1/2}(A,cH) = D_{1/2}(A/c,H)`, and for `|H| > 8 log₂ p` SI₁ on `(·, H)` is equivalent to `M_H < |H|/2`. What is provable about `M_H` is only the Weil range: `M_H² ≤ p − |H|` (one coset of the second moment: `|H| M_H² ≤ Σ_x T_H(x)² = |H|(p−|H|)`), so SI₁ on `(·,H)` is PROVED for `|H| ≥ 2√(p+1) − 1`, and OPEN — it is a `½`-level version of Bourgain's problem at scale `log p` — for `8 log₂ p < |H| < 2√p`. The exact count `|D| = |H|·#{xH : |T_H(x)| ≥ M_H/2}` is what the verifier recomputes.

### 3.3 Cliques and progressions: inner sets (PROVED) and enumeration

**Proposition 3.3 (inner sets).** (i) Let `K' ⊆ F_p^*` be a clique of the Paley graph (`χ(x−y) = 1` for distinct `x,y ∈ K'`), `k = |K'| ≥ 2`, and `(A,B) = (K', −K')`. Then `S(A,B) = k(k−1)` and, with `j₀ = ⌊k(k−1)/(2(2k−1))⌋`,

    Sym_{j₀}(K') := {s ∈ F_p^* : |sK' ∩ K'| ≥ k − j₀} ⊆ D_{1/2}(K', −K').

(ii) Let `r ∈ F_p^*`, `U_L = {r^i : 0 ≤ i < L}` with the `L + 2⌊k/4⌋` powers `r^{−⌊k/4⌋}, …, r^{L−1+⌊k/4⌋}` distinct, `A = U_k` (`k ≤ L`), and `B = N(U_L) = {b ∈ F_p^* : χ(u+b) = 1 ∀u ∈ U_L} ≠ ∅`. Then `S(A,B) = k|B|` and

    {r^j : −⌊k/4⌋ ≤ j ≤ L − k + ⌊k/4⌋} ⊆ D_{1/2}(A,B),   so   |D_{1/2}(A,B)| ≥ L − k + 1 + 2⌊k/4⌋.

*Proof.* (i) `g(s) = Σ_{x∈sK'} Σ_{y∈K'} χ(x − y)`; for `x ∈ sK' ∩ K'` the inner sum is `k−1`, for `x ∉ K'` it is `≥ −k`. With `j = |sK' ∖ K'|`: `g(s) ≥ (k−j)(k−1) − jk ≥ ½k(k−1)` iff `j(2k−1) ≤ ½k(k−1)`. (ii) `T_B(u) = |B|` for `u ∈ U_L`, so `g(r^j) = Σ_{i<k} T_B(r^{i+j}) ≥ (k−e)|B| − e|B|` where `e = #{i < k : i+j ∉ [0, L−1]} ≤ ⌊k/4⌋` in the stated range, and `(k − 2⌊k/4⌋)|B| ≥ ½k|B|`. ∎

For `k = L` (ii) is the crux note's Theorem 6.2. Enumeration (results file, `cliques`): for every prime `p ≡ 1 (mod 4)`, `13 ≤ p ≤ 397`, all maximum cliques containing `{0,1}` (arc-transitivity makes this exhaustive up to affine equivalence; for `p > 241` a random sample of 300 of them) and *all* translates `K' = K + c` with `0 ∉ K'`: 2 324 872 rectangles. `|D_{1/2}| = 1` in the majority of cases (median `1` at every `p ≥ 17`); the maximum ratio `|D|/log₂ p` is `6.01` (`p = 101`, `k = 5`, `|D| = 40`); among the cliques with `k ≥ 8` (`k² ≥ 64`, inside SI's size hypothesis) the maxima are `|D| = 38` at `p = 373` (`4.45 log₂ p > 2 log₂ p`) and `34` at `p = 269` (`4.21 log₂ p`), and they violate SI₂: the shortest progression containing `K'` has length `74` resp. `101` `> 2k` (verifier `clause2_violations_k_ge_8`: seven primes `p ∈ {269, 277, 293, 313, 353, 373, 397}`); every such rectangle has `z² = k²(k−1)²/R ≤ (k−1)² < 8 ln p`, so none is in the SI\* range (`n_rectangles_z8 = 0` for all `p ≤ 400`). ### 3.4 The moment method (PROVED obstruction) and what SI\* needs

Let `θ = ½|S| ≥ ¼mn` and `L(θ) = #{t : |g(t)| ≥ θ} ⊇ D`. The crux note's Corollary 4.1 gives, for `k ≥ 1`,

    L(θ) ≤ θ^{−2k}[ p N_k + (2k−1)√p (mn)^{2k} ],   N_k ≤ (2k−1)!! R^k.

For `k ≥ 2` the second term alone is `≥ (2k−1)√p·(mn/θ)^{2k} ≥ (2k−1)√p·2^{2k} ≥ 48√p > 8 log₂ p` for every `p` (since `mn/θ ≥ 2`), so no `k ≥ 2` can certify SI₁ for any sizes; for `k = 1` the bound is exact (Prop. 3.2) and certifies precisely the window of §3.1. This is the "`√p` floor" of crux Prop. 4.2 in the form relevant here: for `mn ≤ √p` the `k = 1` bound `16p/max(m,n)` is `≥ 16√p`, and for no sizes is it `O(log p)` unless `max(m,n) ≫ p/log p`.

What SI\* needs instead is *Gaussian* moments. **Proposition 3.4 (CONDITIONAL, PROVED as an implication).** Suppose for some `k ≥ 1` that `Σ_{t∈F_p} g(t)^{2k} ≤ Γ·p·(2k−1)!!·R^k`. Then `|D_{1/2}| ≤ Γ p (2k−1)!! (4/z²)^k`, and choosing `k = ⌊z²/8⌋` with `z² ≥ 8 ln p` gives `|D_{1/2}| ≤ 4.03·Γ`. *Proof.* `|D|θ^{2k} ≤ Σ_t g^{2k}`, `θ^{2k} = (S²/4)^k = (z²R/4)^k`; and `(2k−1)!! ≤ √2 e^{1/24}(2k/e)^k` (Stirling), so `(2k−1)!!(4/z²)^k ≤ 1.48·(8k/(ez²))^k ≤ 1.48 e^{−k} ≤ 1.48e·e^{−z²/8} ≤ 4.03/p`. ∎ So SI\* with `K log₂ p` would follow from Gaussian `2k`-th dilation moments up to a factor `Γ ≤ K log₂ p/4.03` at `k ≈ z²/8 ≈ ln p`. The termwise-Weil bound has `Γ_Weil = 1 + (2k−1)√p(mn)^{2k}/((2k−1)!!R^k p)`, i.e. the non-square part `W_k = Σ_{π non-square} Σ_t χ(P_π(t))` must exhibit a saving of

    (2k−1)(mn)^{2k} / ( (2k−1)!! R^k √p · Γ )  ≥  (mn/R)^k (mn)^k / ( (2k−3)!! √p Γ )

over the trivial bound `(2k−1)√p·#tuples`. At `k = 2` the required saving is `≈ (mn)²/√p` (random-like `R ≈ mn`), i.e. none at all for `mn ≤ p^{1/4}` — but `k = 2` certifies nothing (even with `Γ = 1` it gives `|D| ≤ 48p/z⁴`, which is `≤ 2 log₂ p` only for `z² ≳ √(24p/log₂ p)`); at the required `k ≈ ln p` the saving is `p^{ln(mn) − ln ln p − ½ − O(1)}`, which is `> 1` exactly when `mn ≳ e^{1/2}·ln p`, the SNR threshold. So a proof of SI\* must produce cancellation *across* the `(mn)^{2k}` complete character sums `Σ_t χ(P_π(t))` of degree `2k ≈ 2 ln p` — the Weil bound used tuple by tuple is off by a polynomial factor in `p` — and, by crux Prop. 4.6, must do so using only `{σ_r}` data, which is possible in principle since `D` is a dilation-orbit invariant (unlike `C`).
